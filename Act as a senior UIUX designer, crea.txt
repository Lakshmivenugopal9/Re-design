3. ATTENDANCE TRACKER FUNCTIONAL REQUIREMENTS
Preserve and implement all of the following requirements. If an existing feature already works, retain it and improve its presentation rather than replacing it.

FIRST OPEN:
- Open directly into the app without mandatory login or signup.
- Do not require a phone number or email.
- Contact details may be optional in the future for notifications, only with user permission.

MAIN DASHBOARD:
- Display today's day and date prominently.
- Show today's scheduled classes and their attendance status.
- Provide clear Present and Absent actions for each eligible class.
- Show each subject's attendance percentage before marking and update it immediately after marking.
- Do not show attendance-marking controls for holidays or unscheduled classes.
- Include an Add Class feature for the selected day.

DATE NAVIGATION AND ATTENDANCE:
- Clicking the displayed date opens a full calendar.
- Allow attendance entry or correction for past dates only.
- Never allow attendance marking for future dates.
- Provide quick navigation to yesterday and the day before yesterday.
- Show the correct timetable for the selected past date.
- Allow the user to replace a scheduled subject when the actual class was different, and add an extra class that was not on the original timetable.
- Allow previously entered attendance to be corrected without losing other records.

SIDEBAR:
Include exactly these primary sections:
1. Overall Attendance
2. Manage Subjects
3. All Subjects
4. Settings

OVERALL ATTENDANCE:
Calculate overall attendance using total classes attended divided by total classes held across all subjects, multiplied by 100. Display the percentage clearly and present useful visual summaries without misleading calculations.

MANAGE SUBJECTS:
- Add, edit, and delete subjects.
- Store subject names and their scheduled class days.
- Display attended classes, total classes, and current attendance percentage.
- Update attendance calculations consistently when valid records change.

ALL SUBJECTS:
- List all subjects.
- Clicking a subject opens its attendance calendar.
- Use a proper monthly calendar layout from Sunday through Saturday.
- Show attendance status for recorded dates.
- Support month navigation and past-date corrections.
- Block future-date attendance entry.

TIMETABLE SETUP AND UPDATES:
- Support manual timetable setup and timetable upload.
- Provide a clean path for entering the timetable day by day.

- Timetable changes must apply going forward without overwriting historical attendance.
- Preserve the timetable version associated with earlier attendance records.
