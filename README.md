# MyStore – RE:DESIGN Source Project

This is the official starter project for the RE:DESIGN competition.

## Technology

React
Vite
JavaScript
CSS

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Important

This project is provided as the starting point for the
AI-powered redesign challenge.

Participants must redesign the user interface and user
experience while preserving all existing functionality.

Do not remove required pages or features.

Do not include node_modules in the final submission.
